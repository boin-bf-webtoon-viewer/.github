# boin-bf-webtoon-viewer

배리어프리 웹툰 서비스의 **뷰어, 인증, 패키징, 배포** 관련 저장소를 모아 둔 조직입니다.

세부 연동 방식과 운영 절차는 각 저장소의 README, 이슈, 배포 문서를 참고하세요.

## 저장소

| 저장소 | 소개 |
|--------|------|
| [.github](https://github.com/boin-bf-webtoon-viewer/.github) | 조직 공통 프로필, 기본 설정, 워크플로우 관리 |
| [bf_webtoon_frontend](https://github.com/boin-bf-webtoon-viewer/bf_webtoon_frontend) | 웹툰 뷰어 프론트엔드 |
| [bf_webtoon_backend](https://github.com/boin-bf-webtoon-viewer/bf_webtoon_backend) | 뷰어 백엔드 API |
| [bf_webtoon_authTest](https://github.com/boin-bf-webtoon-viewer/bf_webtoon_authTest) | 포털·로그인 시연용 auth |
| [bfw_usertest](https://github.com/boin-bf-webtoon-viewer/bfw_usertest) | 사용자 테스트용 포털/진입 환경 |
| [bf_webtoon_ampas](https://github.com/boin-bf-webtoon-viewer/bf_webtoon_ampas) | 콘텐츠 패키지 저장 연동 |
| [bf_webtoon_webtoontoEncEpu](https://github.com/boin-bf-webtoon-viewer/bf_webtoon_webtoontoEncEpu) | 웹툰 EPUB 패키징 도구 |
| [LCP_TEST](https://github.com/boin-bf-webtoon-viewer/LCP_TEST) | EPUB 암호화·메타데이터 도구 |
| [bf-contentsToEPUB](https://github.com/boin-bf-webtoon-viewer/bf-contentsToEPUB) | CMS export → EPUB 변환 |
| [structure_upload](https://github.com/boin-bf-webtoon-viewer/structure_upload) | 구조화 패키지 업로드/인제스트 도구 |
| [Forensic_watermark](https://github.com/boin-bf-webtoon-viewer/Forensic_watermark) | 포렌식 워터마크 실험/유틸리티 |
| [bf_view_charts](https://github.com/boin-bf-webtoon-viewer/bf_view_charts) | 차트·배포 리소스 및 Kubernetes 관련 자산 |

## 참고

- 현재 조직 페이지에서 공개로 바로 보이는 저장소는 제한적이며, 대부분의 작업 저장소는 Private로 운영됩니다.
- 접근 권한은 조직의 People / Teams 설정으로 관리합니다.
- 이 문서는 조직 Overview 표지용 안내 문서입니다.

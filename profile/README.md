# boin-bf-webtoon-viewer

배리어프리 웹툰 **뷰어·인증·패키징** 관련 저장소를 모아 둔 조직입니다.

내부 연동·배포 세부사항은 각 Private 저장소 README와 이슈를 참고하세요.

## 저장소

| 저장소 | 소개 |
|--------|------|
| [bf_webtoon_frontend](https://github.com/boin-bf-webtoon-viewer/bf_webtoon_frontend) | 웹툰 뷰어 프론트엔드 |
| [bf_webtoon_backend](https://github.com/boin-bf-webtoon-viewer/bf_webtoon_backend) | 뷰어 백엔드 API |
| [bf_webtoon_authTest](https://github.com/boin-bf-webtoon-viewer/bf_webtoon_authTest) | 포털·로그인 시연용 auth |
| [bf_webtoon_ampas](https://github.com/boin-bf-webtoon-viewer/bf_webtoon_ampas) | 콘텐츠 패키지 저장 연동 |
| [bf_webtoon_webtoontoEncEpu](https://github.com/boin-bf-webtoon-viewer/bf_webtoon_webtoontoEncEpu) | 웹툰 EPUB 패키징 도구 |
| [LCP_TEST](https://github.com/boin-bf-webtoon-viewer/LCP_TEST) | EPUB 암호화·메타데이터 도구 |
| [bf-contentsToEPUB](https://github.com/boin-bf-webtoon-viewer/bf-contentsToEPUB) | CMS export → EPUB 변환 |

## 참고

- 대부분 Private입니다. 접근 권한은 조직 People / Teams에서 관리합니다.
- 이 문서는 조직 Overview 표지용입니다.
